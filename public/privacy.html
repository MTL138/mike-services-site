Privacy Policy: SideKick Mail Assistant

Last updated: October 1, 2026

SideKick Mail Assistant is a personal tool built and used by one individual, Michael Lee ("the developer"), to help manage his own email. It is not offered to the public and has no other users.

What data the app accesses

The app requests read-only access to the developer's own Gmail account (scope: https://www.googleapis.com/auth/gmail.readonly). It reads message sender, subject, date and message text so that it can identify important messages and reminders.

What the app does with the data

  • It classifies and summarizes incoming messages, for example school notices, activity schedules, bills and work related messages.
  • It produces a short summary for the developer. It never sends, deletes, labels or modifies any message.
  • Limited portions of a message (such as sender, subject and a text excerpt) are sent to the Claude API operated by Anthropic for classification. This is done only to produce the summary. Data is handled under Anthropic's API terms.

Storage

Authorization tokens and summaries are stored on a private computer owned and controlled by the developer. Access is restricted to the developer's own system account.

Sharing

The data is not sold, not used for advertising, not used to train generalized AI models by the developer, and not shared with anyone other than the processing described above.

Google API Services User Data Policy

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The developer can revoke the app's access at any time at myaccount.google.com/permissions and delete the locally stored tokens and summaries at any time.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
